# Фонарщик глубин

2D-платформер в жанре метроидвании на чистом JavaScript и Canvas. Три главы, рывок, двойной прыжок и босс. Герой, враги и мир оригинальные; игра не связана с Hollow Knight и его авторами.

## Запуск

Откройте `index.html` в браузере. Сборка и установка не нужны.

## Управление

| Действие | Клавиши |
|---|---|
| Идти | ← → или A D |
| Прыжок | пробел, W или ↑ |
| Удар | J или X |
| Рывок | K, Shift или C |
| Лечение (стоя) | H |
| Начать | Enter |

На телефоне есть кнопки под игровым экраном.

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка `main`, папка `/ (root)`.
